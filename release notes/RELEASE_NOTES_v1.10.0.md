# Release Notes - Version 1.10.0

**Release Date:** 2026-04-08
**Type:** Feature Update & UI Enhancements

## 🎉 What's New

### 🚀 Major Features

1. **Extension Feedback & Engagement System** - A smart engagement engine that triggers gentle review prompts based on export activity. Includes a persistent feedback/share footer in the settings menu.
2. **Starred Highlights Browsing** - Navigate effortlessly through your favorited highlights using a dedicated view in the review tab with next/previous controls.

### ✨ Key Features

#### 1. Engagement & Feedback

- Activity-based prompt triggers avoiding intrusive disruptions.
- Persistent actionable footer ensuring users always have a way to share feedback.

#### 2. Enhanced Review Mode

- Interactive "Starred" statistics toggle to enter a dedicated favorite highlights viewing mode.
- Intuitive navigation controls tailored for reviewing top content.

#### 3. Aesthetics & UI Polish

- Fully upgraded glassmorphism aesthetic resolving layout alignment, spacing inconsistencies, and inactive tab contrast issues.
- Streamlined header baselines for cross-browser visual consistency.

## 🔧 Technical Improvements

- Created structured `repository-metadata.json` and a centralized DOM Selectors reference (`DOM_SELECTORS.md`).
- Aligned `ABOUT.md` documentation and Google Privacy Policy with the current technical stack and permissions.
- Revamped Chrome Web Store descriptions with SEO optimizations for batch export transparency.
